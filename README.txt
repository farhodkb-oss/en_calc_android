# en_calc APK build

Файлы:
- main.py — приложение Kivy
- buildozer.spec — настройки Android-сборки
- .github/workflows/build-apk.yml — автоматическая сборка APK в GitHub Actions

После загрузки проекта в GitHub:
1. Откройте вкладку Actions.
2. Выберите Build Android APK.
3. Нажмите Run workflow.
4. После завершения откройте запуск и скачайте Artifact `en-calc-apk`.
